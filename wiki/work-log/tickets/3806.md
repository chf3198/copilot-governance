## Body

Extend `scripts/accountable-team-verify.js` with **AT4 — `AT4_active_ticket_no_owner`**:
an *active-execution* (non-terminal, non-empty status) **non-epic** ticket that carries
**no** `accountable-team:*` label is flagged (advisory-only). This is the positive
ownership-**coverage** complement to AT3 (which keeps transient `role:*` off terminal
tickets). Ships the previously-missing sibling spec `accountable-team-verify.spec.js`
(covering AT1–AT4) and a `harness-self-test-registry.json` entry, closing a
validator-discipline (#1893) gap for this validator.

Epic lineage: E3 / Epic #2345 (ownership vs accountability), design synthesis #2346 §5.

## Acceptance criteria

- AC1 AT4 flags active non-epic tickets with no owner; exempts Epics, terminal/backlog
  states, empty/unknown status, and active tickets that already name an owner.
- AC2 CLI preserves advisory-first (always exit 0).
- AC3 sibling spec self-executes (Node built-ins), exits non-zero on failure, covers AT1–AT4.
- AC4 registry entry present.
- AC5 enforcement surface stays 0-unwired; telemetry baseline refreshed.
