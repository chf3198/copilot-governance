## Body

Optimally remediate the ~764-path live-harness baseline drift on the canonical checkout by having
**multiple parallel sessions safely divide and conquer** — capture-as-baseline (never discard, #3801)
into `origin/main`, one disjoint **lot** at a time, each with segment web research, cross-family
consensus, frequent testing, and sturdy rollback.

**The simple system** (git remote = the coordinator; see `epic-3818/COLLAB.md`):
1. **Disjoint lots** — 12 glob-defined slices of the drift, provably non-overlapping + total (`lots.md`).
2. **Atomic claim** — pushing `claim/3818-<lot>` is atomic on the remote; first push wins (git = mutex).
   No shared mutable ledger; state is READ from `git ls-remote` + `gh pr list`.
3. **Reversible** — capture is a faithful, idempotent `cmp`-clean content snapshot; every step has a
   compensator (drop branch / `git revert`); pre-capture `.pre.patch` is the rollback source.

**Per-lot lifecycle:** claim → research (web) → isolate (own worktree) → snapshot compensator → capture
(cmp-clean) → **test gate** → **$0 cross-family consensus** → PR → CI-green → squash-merge → release claim.

**Grounding:** work-stealing atomic-claim protocols, saga compensating-transactions (idempotent
forward+compensate, test the failure path), git-remote-as-coordination.
